Problema y objetivo

Un inventario que nunca se descuadra

1

Control de existencias

Entradas, salidas y ajustes. El stock solo cambia mediante movimientos y nunca queda en negativo.

2

Alertas automáticas

Cada producto se clasifica como normal, con stock bajo o agotado según su mínimo.

3

Acceso por roles

Administrador y almacenero, con sesión por token JWT y contraseñas cifradas con bcrypt.

SQL++ y concurrencia

Consultar como en SQL, escribir sin descuadres

SQL++ · productos con alerta
SELECT p.codigo, p.stockActual
FROM productos AS p
WHERE p.estado = "ACTIVO"
  AND p.stockActual <= p.stockMinimo;
Dos salidas a la vez
  • Cada documento tiene un CAS (versión).
  • Si otro cambió el producto, Couchbase detecta el conflicto.
  • La API repite la transacción con el stock nuevo.
